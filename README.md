## Описание работы
Целью данной лабораторной работы является освоение манипуляций с DOM-деревом (поиск элементов, изменение структуры, добавление и удаление строк таблицы), обработка пользовательских событий, обеспечение отказоустойчивости (проверка элементов) и сохранение клиентского состояния с помощью `localStorage`.

## Реализованный функционал (Вариант 6)
1. **Интерактивные элементы:** 
   - **Добавить фильм:** Запрашивает через `prompt` название, год и статус фильма, после чего динамически создаёт строку таблицы (`<tr>` с ячейками `<td>`) и добавляет её в `<tbody>`.
   - **Очистить список:** Удаляет все сохранённые фильмы из таблицы и хранилища (с предварительной проверкой состояния).
   - **Скрыть/показать таблицу:** Переключает видимость контейнера таблицы с помощью CSS-класса `.hidden`.
   - **Сменить тему:** Переключает светлую и тёмную темы страницы.
2. **Сохранение состояния (`localStorage`):** 
   - Список добавленных фильмов и выбранная пользователем тема сохраняются в `localStorage` и автоматически восстанавливаются при повторной загрузке страницы.
3. **Обработка ошибок:** 
   - Перед вызовом методов и навешиванием обработчиков событий скрипт проверяет существование элементов в DOM (`if (element)`), выводя предупреждения в консоль в случае их отсутствия.
